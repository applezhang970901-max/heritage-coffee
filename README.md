## 🏛 專案定位與設計理念

### 1. 目標受眾與老錢風調性（Target Audience & Aesthetic）
- **目標客群**：極高淨值人士（UHNWI）、家族藏家、商務菁英、重視隱私與內在寧靜的高品味名仕。
- **風格語彙（Old Money Quiet Luxury）**：
  - **色彩系統**：以咖啡色系為核心——深烘焙黑曜石色（`#0F0A07`）、百年深胡桃木色（`#17110C`）、復古刷紋黃銅金（`#C5A059`）、熟成干邑皮革色（`#8B5A2B`）與骨董羊皮紙白（`#F7F3EB`）。
  - **字體設計**：英文字體選用古典襯線體 `Cormorant Garamond` 與羅馬石刻銘文書寫體 `Cinzel`；中文字體選用溫潤典雅的 `Noto Serif TC`（思源宋體）。
  - **放鬆氛圍**：內建基於 Web Audio API 研發的「黑膠微粒與暖爵士和弦產生器」，營造如同置身青田街百年私邸的靜謐沉浸感。

## 📋 官網核心內容與新增電商功能模組

1. **開店旨意（Philosophy & Heritage）**：
   - 講述家族四代尋豆手藝，堅持不迎合快節奏翻桌率，專注於時間沈澱的美學。
   - 呈現三大品牌核心價值：「稀世微批次珍藏」、「緩慢的時間美學」、「私密與專屬尊榮」。
2. **製做方法（Artisanal Extraction）**：
   - 四大古典萃取工藝：24K 鍍金虹吸萃取、72 小時京都琉璃雙塔冰滴、1961 古董活塞槓桿壓力濃縮、波爾多橡木桶熟成微批次炭火烘焙。
   - 每項工藝皆標註精確萃取參數（水溫、秒數、粉水比）。
3. **特別季節限定商品（Winter Solstice Edition）**：
   - 專屬聚光燈焦點（Spotlight Showcase）呈現「1998 波本單桶陳釀・黑金藝伎咖啡」與「阿爾巴白松露皇家生巧克力磚」，每日僅限量 10 席。
   - 具備「即刻預訂席位」按鈕，自動聯動填入預約表單備註。
4. **典藏菜單（Curated Tasting Menu）**：
   - 涵蓋「頂級珍稀咖啡」與「法式私廚甜點」。
   - 提供「即時關鍵字搜尋」與「分類標籤過濾（全部 / 咖啡 / 甜點 / 季節限定）」。
   - 點擊卡片開啟「品鑑詳情彈窗（Product Detail Modal）」，詳列莊園海拔、處理法、烘焙度與風味筆記。
5. **【新功能】莊園名茶專區與茶包線上選購（Artisanal Tea Bags Store）**：
   - 涵蓋：阿里山樟樹湖百年高山金萱、日月潭皇家紅玉18號、1988年雲南易武陳年熟普洱、北埔東方美人白毫烏龍。
   - **多規格自選切換**：每一款茶包均支援「典藏絲囊隨行袋 10入盒裝」、「英倫胡桃木手造禮盒 20入裝」、「私人窖藏原葉密封金罐 75g裝」，價格動態即時切換。
   - **數量增減（Stepper）**：可自選 1～99 盒購買數量。
6. **【新功能】典藏購物袋抽屜（Cart Drawer）**：
   - 點擊導航列「🛍 購物袋」或商品卡片「加入典藏購物袋」後自動滑出。
   - 即時計算商品小計、免運門檻、支援增加、減少數量與單項刪除。
7. **【新功能】試跑結帳流程（Simulated Checkout Flow）**：
   - 包含收件貴賓姓名、專屬電話、配送私邸地址、時段選擇、手寫火漆封蠟感謝函加購。
   - 頂級尊榮支付模擬：Centurion 黑卡禮遇簽帳、Apple Pay、私人家族辦公室月結、加密資產信託支付。
   - 結帳送出後生成正式「LH 火漆封蠟收據憑證（Order Receipt）」與訂單單號，並保存至本地資料庫。
8. **店內設計（Spatial Architecture）**：
   - 四大沉浸式私密空間圖文巡禮：百年英倫橡木圖書沙龍、黑白根大理石手沖鑑賞席、法式私人庭園溫室花廳、極私密名仕雪茄與鑑賞廂房。
9. **VIP 席位預約系統（Bespoke Reservation）**：
   - 尊榮表單設計（姓名、專線、預約沙龍、到訪人數、日期、時段與特殊需求）。
   - 提交後自動產生專屬單號，存入本地資料庫並即時連動至後台。

## 🛠 本地預覽與操作指南

因為本專案採用最純粹乾淨的 HTML5 + CSS3 + Vanilla JavaScript ES6 架構：
1. **直接開啟**：直接雙擊 `index.html` 即可在任一瀏覽器（Chrome, Edge, Safari）中完整運行所有功能！
2. **茶包線上購物測試**：
   - 滾動至「莊園名茶・東方風雅典藏茶包」區塊。
   - 點選任一款茶包之規格（如「英倫胡桃木手造禮盒 20入」），觀察價格即時連動變更。
   - 點選「+」調整數量，點擊「加入典藏購物袋」。
   - 右側滑出購物袋抽屜，點擊「前往貴賓結帳禮遇」填寫表單並送出。
   - 查看生成的尊榮火漆封蠟收據憑證。
3. **後台管理檢視訂單**：
   - 點擊網站導航列右上角的「**⚙ 典藏管家**」按鈕。
   - 切換至「**📦 尊榮茶包訂單 (CRUD)**」分頁，即可查閱剛才試跑結帳之訂單，並可點擊「變更狀態」切換為「已出貨 (黑貓冷鏈)」。
